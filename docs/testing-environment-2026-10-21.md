# 本轮测试环境与验收边界

用户已确认当前运行于 WSL，必要时可以自行创建 Docker 环境。本地 SDK 工作不等待用户提供服务器或账号。

## 现有方式

本轮沿用仓库自带的 PHP CLI、Python 测试控制器及浏览器测试程序。数据库、认证文件和服务均使用控制器创建的独立测试数据；不连接业务数据库。既有历史检查包括回环 HTTP／TLS、本机 SMTP、临时 Redis／MySQL 和浏览器虚拟认证器，具体执行时间及源码身份见[验证记录](verification.md)，不能合并成当前候选整轮通过。

| 环境 | 创建及隔离方式 | 本轮用途与验收边界 |
| --- | --- | --- |
| PHP／SQLite／FileStore | WSL 内解释器、临时数据库与私有目录 | SDK 状态、权限、备份恢复、并发及拒绝路径；真实文件与 SQL，不是仅模拟调用 |
| MySQL | `tests/mysql_check.py` 自建临时实例，Unix socket、`--skip-networking`；结束关闭并删除数据目录 | 两端真实 MySQL 后端；专用测试账号的元数据可见性不代表生产普通账号权限 |
| HTTP／TLS／SMTP | 测试程序启动回环服务、临时证书与测试收件数据 | 协议与 SDK 流程；不代表第三方邮件投递、目标站点部署或生产证书已验收 |
| 浏览器／WebAuthn | 浏览器自动化及虚拟认证器 | 网页交互与软件认证器；实体密钥、手机／系统通行密钥仍需实际设备 |
| OIDC | 适配包独立依赖；可自建测试发行方 | 本地协议及异常流程可以自行验证；第三方目标发行方的账号策略、关联／注销须单独记录 |
| 代理／WAF | 可自建反向代理测试链及规则 | 本地可信头、Host／TLS、重复头与拒绝行为；生产边缘网络、源站隔离和实际规则须在目标环境验证 |

当前 F01 专项使用 PHP7.2.34 与 PHP8.5.9。PHP7.2 普通墙上时钟在实际运行中出现倒退，原逻辑安全超时；后续专项使用私有原生 `CLOCK_MONOTONIC` 扩展和 sodium，不修改系统 PHP。源码、构建及运行环境摘要均在[边界接入证据](state-boundary-integration-2026-10-21.md)中，不能省略这个限定。

## 何时才需要补充外部信息

优先自行完成可重复的本地环境。具体适配就绪后，才需要目标宿主／第三方发行方／邮件服务／实际代理的名称、测试地址和非敏感配置，以及可操作实体认证设备的验收人员。密码、密钥通过原有安全配置注入，不在对话、命令行或验收日志中收集。

2026-10-21 本次查询确认 WSL2 内有 Docker CLI，但 `docker info` 在 8 秒查询上限内未返回（退出 124），没有创建容器。现有隔离控制器能够完成的检查继续使用它；Docker 本身不是本轮验收目标。需要新增服务时选择可用的本机进程或容器，记录准确版本、端口、数据目录、启动／退出与清理结果。未实际创建或运行的环境保持“未执行”，不会因为列在本表就算通过。

当前执行范围仍为[有限周期计划](full-plan-2026-10-21.md)的 31 项、80 个有效工作小时上限。自建环境不增加需求、不延长上限；局部绿色结果不关闭完整 F01 或 R1—R6。
