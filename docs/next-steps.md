# 近期执行安排

本页按[总体规划](roadmap.md)推进具体工作，不再维护另一套版本路线。当前事实以[执行状态](execution-status.md)、[功能清单](features.md)及[验证记录](verification.md)为准。

1. 以2026-10-13最终规划对话整理产品需求及执行边界，统一README、文档索引和功能矩阵。
2. 七种最小配置预设与现有原生登录/重置/上传/API等示例配套，核对默认值、单位、失败处理和宿主职责；在当前九个PHP CLI验证。
3. 核对演示总览、各能力入口、源码隔离及当前服务状态。修改界面时验证相应HTTP/浏览器路径；未修改的底层驱动不重复无关大矩阵。
4. 整理API候选和发布工作单，完成作者代码复核及适当回归；独立复核未完成时如实标记，不创建未经允许的子代理或冒称独立审计。
5. 完成可供审核的发行候选后报告功能、兼容性、证据和限制。公开推送、标签/Packagist及实际旧站接入由用户明确指令触发。

当前暂不添加TOTP、独立AutoBan、系统Fail2ban、全站运营平台或框架自动接管。跨框架能力通过独立接口、明确宿主边界和示例保持；既有框架安全机制可以继续使用。

统一演示入口：[72.rocky.wsl/SoSecurity](http://72.rocky.wsl/SoSecurity/)。每个新功能交付须同时提供示例、演示、正常/拒绝/故障说明和测试；没有真实服务配置时显示未执行。
