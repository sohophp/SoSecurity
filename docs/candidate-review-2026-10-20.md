## 问题清单

### F01：完整有效旧备份可能恢复失效认证状态

- 严重程度：高，已知安全阻塞项，保持未关闭。
- 来源与位置：[状态新鲜度说明](account-factor-freshness.md)、[交接说明](session-handoff-2026-10-20.md)；主 SDK `Auth/SessionRegistry.php` 的 `verify()`／`revokeAll()` 与可恢复的状态存储。该结论来自候选已有明确复现记录和未交付边界，**不是本轮重新完成完整 SQL＋会话＋因子备份复现**。
- 触发与影响：恢复完整有效旧 SQL 与认证状态后，旧版本、HMAC 和历史集合仍可一致，原已失效的会话可能重新认证。工作进程栅栏不能独自证明普通认证状态最新。
- 本轮验证状态：源码／文档边界已检查；补充的 FileStore 子场景探针在 PHP 7.2／8.5 都因审查脚本将 `TestClock` 错传给 `FileStore` 的 namespace 参数而退出 255，**尚未执行到备份／撤销操作，不是产品失败或本轮复现证据**。不追加轮次，原始失败日志保留。
- 处置建议：独立立项固定全部入口、独立权威持久化、未知结果恢复及权限边界；不得直接把 `/tmp` 原型搬入 SDK 后宣称修复。

### F02：幂等 SQL 元数据在字节校验前返回 PHP，异常大字段导致 OOM

- 严重程度：中，可用性阻塞项；限于已经启用 SQL 幂等的使用方。需要数据库中存在异常／被篡改的超长元数据，**没有证据表明普通外部请求能通过组件写入该异常值**。
- 源码位置：`src/Idempotency/SqlExecutor.php:45` 的 `root()`，尤其第 47 行直接 `SELECT` 原字段并 `fetch()`；`src/Idempotency/State.php` 的 `read()` 在返回 PHP 后才校验摘要长度。`resources/sql/idempotency-sqlite.sql` 使用无实际字节上限的 TEXT。`history()`／`record()` 也有直接选取元数据的代码，但本轮只动态复现根的 `seal` 字段，不将该结果扩展成所有字段或后端已验证。
- 复现：使用准确候选 DDL 创建自有临时 SQLite；正常空查找通过后，在 SQL 内用 `hex(zeroblob(8388608))` 生成 16 MiB 的错误 `seal`，避免测试代码先分配大字符串。随后调用真实 `SqlExecutor::lookup()`。
- 已执行但失败：PHP 7.2.34／8.5.9 在 `memory_limit=8M` 下均于第 47 行 `fetch()` 退出 255，提示申请 16,777,248 字节导致内存耗尽；未能抛出受控 `StorageException`。这两条失败就是缺陷证据，未为了得到通过而重跑或修改产品。
- 副作用核查：父进程重新打开自有数据库，根记录仍为 1 条、异常字段仍为 16,777,216 字节、执行记录为 0；未调用业务 handler。不把这个只读探针当作所有业务事务回滚已验证。
- 证据：[复现脚本](candidate-review-evidence-2026-10-20/reproduce-idempotency-metadata.php)、[PHP 7.2 日志](candidate-review-evidence-2026-10-20/idempotency-metadata-php72-probe.log)、[PHP 8.5 日志](candidate-review-evidence-2026-10-20/idempotency-metadata-php85-probe.log)及执行记录中的 `after_probe`。子进程已回收，两份临时数据库已删除。
- 处置建议：按幂等字段契约在 SQL 返回前限制类型及字节，覆盖根、记录、历史和维护查询；保持合法正文／空值／二进制能力，异常操作在业务回调前拒绝。不能仅提高 PHP 内存上限或截断异常值。本轮不修复。

### F03：OIDC 依赖文档写了与实际不同的允许版本范围

- 严重程度：低，文档待修复项，单独不构成运行时漏洞。
- 位置：`docs/dependency-inventory.md` 的 OIDC 表格写允许 `^1.0.2`；准确候选 `integrations/oidc/composer.json` 写精确 `1.0.2`。
- 影响与验证：已静态核对，审查者据文档会误判未来安装是否自动接受其他 1.x；未执行新的依赖解析／公告审计。
- 处置建议：修正文档以匹配清单，保留 PHP `<8.4` 和真实消费者锁文件的独立边界。本轮只登记，不顺带升级依赖。
