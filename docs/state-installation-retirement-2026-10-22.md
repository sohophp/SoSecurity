# 新凭据安装中的原因子退役

日期：2026-10-22。属于既定 P1／G4 的安全恢复闭环，31 项／80 个有效工作小时上限保持。此前新凭据安装更新了账号和目录，但原因子物理文件仍可保留有效证明材料；本组将目录认证的准确原因子纳入安装效果，不自动重新启用账号。

## 安装与续办行为

新准备的安装清单使用格式 4；同时清空会话的清单使用格式 5。在原格式 2／3 字段后追加 retirement：原字节 SHA-256（文件不存在时为 null）、永久失效标记的固定完整字节。存储键和文件引用由认证前像中的 prior 坐标及准确原生存储确定，不在清单中重复保存。新字段进入既有清单指纹、独立强审批、pending 回执及耐久恢复审计；没有新增公开方法、可执行回调、任意文件路径或 SQL。

旧坐标必须来自认证后的原目录指针，并处于已声明的完整文件来源；与新因子或会话文件重合时提前拒绝。准备阶段读取旧永久容器，认证受管理封装并校验因子状态及原代际；仅目录明确指向本账号传统坐标时允许原始格式 1。保留既有迁移回执，固定写入受 HMAC 认证、payload 为 null 且永不到期的标记，不删除文件或将其转换为可重新初始化的空状态。原文件不存在或已退役时也形成明确后置条件。

效果顺序为：持久 pending → 写入新因子 → 永久退役原因子 → 可选清空会话／持久登录登记 → 原账号／目录记录／账本根的同事务比较更新 → 消费候选 → 复核完整来源和审计。每次物理替换前仍检查独立当前批准、准确活动能力和截止时间。新密码、因子、会话代际和失效标记均为审批时固定值。

准备后旧文件变化时，审批消费和 pending 之前拒绝。进入效果阶段后，原因子只能是已封存的原字节或准确失效字节；第三种字节拒绝。中断或确认丢失保持 quarantined／pending，不能退还旧批准或恢复原文件。新的读取器从持久回执重建相同效果，经新的 resolve 强批准后续办。

## 格式兼容与限制

格式 2／3 的严格解析与既有效果仍保留，不能自动追加未审批的原因子破坏操作。它们不具备本组的物理退役保证；完整恢复启用仍须另外核对旧授权处置。新格式要求所有相关读取器协调升级；旧读取器不会接受格式 4／5 的安装回执。隔离根 16 KiB、审计记录 64 KiB 及现有审计容量保持，最大回执仍在消费审批前预检。

本组只处理当前目录指向的原因子；历史槽位、未完成工作流、其他账号和一次性证明仍须按原有完整清单处置。不能以本次安装代替全域因子盘点、工作进程栅栏、旧证明退役或最终启用审批。

## 验证范围

初轮固定八条命令记录在 [execution.json](state-installation-retirement-evidence-2026-10-22/execution.json)，输入清单包括 src、tests、resources、examples、bin 及 Composer／静态配置。原计划每个运行时／后端组合执行十个安装／会话专项与三个真实 SIGKILL 点；实际四组均在第八个会话专项的容量预检处失败，后续会话续办／拒绝和强杀未执行。此前各七个专项及随后两端公开契约、PHP7.2 目标静态分析、821 个 PHP 文件语法检查通过；初轮整体未通过，执行中输入未变。新增控制器沿用自建 Unix socket／禁 TCP MySQL；不连接业务数据库，也未创建 Docker 容器。

原生验证检查复制真实因子字节，使用独立有效本地权威，刻意不借助原账号禁用或隔离根的拒绝来获得绿色：安装前旧 TOTP／恢复码有效；安装后两者拒绝；新 TOTP 可用。检查同时覆盖迁移元数据保留、原文件缺失／已退役、篡改坐标／活跃 payload、准备后旧字节变化、全 SQL 前后像、旧批准拒绝及新批准续办。旧格式专项验证兼容图像的读取、无效果和禁止借续办对象启动新安装；不将其称为真实历史进程完整恢复。

真实强杀点分别在原因子重命名前、重命名后，以及会话重命名后。恢复在新进程、新 PDO 和新服务图中执行，核对原字节或永久失效字节、SQL 是否提交、旧批准失效、最终固定标记及临时文件清理。确定性持久化失败另覆盖新文件、旧因子和 SQL 后续办；二者分别记载。

开发预检曾因测试清理函数只支持单层目录而失败，原日志 [preflight-test-cleanup-failure.log](state-installation-retirement-evidence-2026-10-22/preflight-test-cleanup-failure.log) 保留。修正为逐个清理自建子目录，并清理该次准确临时目录；该失败不是产品旧因子缺口的执行反例。随后 PHP8.5 原生证明预检通过，日志 [preflight.log](state-installation-retirement-evidence-2026-10-22/preflight.log) 对应冻结前测试内容，不能并入冻结后的八条命令。

压缩后单独冻结 [compact-execution.json](state-installation-retirement-evidence-2026-10-22/compact-execution.json)，固定八条命令：四种组合仅重跑受影响的原因子退役、六类安装续办和三个会话专项，再执行三个实际强杀点；另核对两端公开契约、静态和语法。该轮不重复不受影响的旧审计协议专项，也不把初轮的七个通过结果拼为压缩后完整十专项或九版本整轮。**压缩后已执行并通过：固定八条命令全部退出 0，执行中输入保持不变。** 四种组合的五个受影响专项分别为 153／379／70／280／71 项，十二个真实 SIGKILL 点全部完成新进程恢复。两端 261 类公开契约、PHP7.2 目标库静态分析和 821 个 PHP 文件语法通过；保留既有可选 turbo 扩展 GLIBC 加载警告。初轮与压缩候选分别留存，不称为同一轮通过。PHP7.2 为既有私有 sodium／posix／原生 CLOCK_MONOTONIC 运行环境，不声明系统原版 PHP7.2 完整验收；[环境记录](state-installation-retirement-evidence-2026-10-22/environment.json) 保存实际版本及解释器摘要。
