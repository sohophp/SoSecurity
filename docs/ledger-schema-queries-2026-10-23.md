# 账本结构查询合并与元数据预算

## 已确认问题与改动

默认MySQL凭据诊断显示，一次失败签发在3.108秒内执行了128次引擎、128次外键和128次触发器检查，列查询260次、索引查询386次。诊断仅统计PDOStatement执行时间，未完整统计准备、取行和PHP开销；不能据此把所有剩余耗时归为非SQL。诊断失败后见证为pending，没有继续操作或恢复。

`SqlSchema::table()`过去分开查询表引擎与列定义，且MySQL列元数据直接fetchAll而没有显式行数／声明长度上限。本批将两个结构查询合为一次，读取最多65行并拒绝超过64列，给引擎、列名、类型声明及排序规则投影设置字节上限。保留InnoDB、精确列类型／非空、主键／索引、外键和触发器检查，不跨观测缓存，不减少身份、因子或会话复核。

独立修前基准的结构查询计数为2，修后为1。已有规范账本声明不变；没有新增公开接口，类型清单仍275。新行为仅明确拒绝超出内部结构预算的元数据。
