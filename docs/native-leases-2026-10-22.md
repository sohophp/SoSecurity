# 保护模式的原生并发租约

## 缺口与接入

原 `Security::leases()` 在启用认证状态边界时通过 `apiStore()` 明确拒绝，未提供租约保护图接入。本批新增 `Account\StateLeaseConnection`；`Security::leases($state)` 和 `LeaseManager` 构造函数末尾的可空 `state` 参数显式选择新路径，旧参数及普通模式保持。公开类型从 272 增至 273，新增连接的公开方法和 `StateOperation::lease`，不是重写旧候选清单。

连接要求准确的边界、见证、完整组合来源、同一 FileStateSnapshot／FileStore、站点、作用域、安全代际和时钟。工厂另检查 `site:shared` 命名空间。保护模式仍拒绝无连接调用，未声明的存储、错误时钟和嵌套入口均拒绝。当前仅接入明确声明的 FileStore，其他后端不能通过此连接冒充受保护来源。

构造必须提供当前权限守卫，签名为 `guard(action, authorityScope, resourceScope, resource, owner)`，返回真实的服务器调用者标识或 null／false。它必须验证实际请求与当前资源权限，不得直接回显客户端传来的 owner。获取、续期、验证和释放要求返回调用者严格等于 owner；初始化、检查和移除须由守卫授予各自独立权限。动作固定为 `leases.initialize/acquire/renew/verify/release/inspect/remove`，不会把请求字符串当作任意管理权限。守卫是受信任的、无业务副作用且可重复调用的宿主依赖，不是 SDK 自动推断的账号角色。

## 原有保护与新增准入

在同一完整来源锁内读取永久账本、校验当前策略及持有者，使用原 LeaseState 状态机生成纯变更；再次核对当前调用者、有效期和物理容量后才写 pending。效果只提交与只读观察一致的原状态和预先计算的变更。普通容量竞争、重复持有者、错误令牌和无状态变化的读取无需推进见证。原有序号、epoch、期限、续期上限、精确令牌清理以及业务 SQL 的围栏条件保留；业务写入仍须实际执行围栏谓词，租约返回本身不授予任意 SQL 权限。

共享时限从入口开始，包含锁等待、准入、写入和返回复核。默认 1000 毫秒，可显式配置 1—30000 毫秒；测试的默认值和 30000 毫秒组合分别记录，不相互替代。永久账本不能带存储到期时间。原生入口的时钟异常和权限守卫异常分别转换为固定 `lease.clock`、`lease.authority_unavailable`，不保留原异常链。

已写 pending 后发生权限拒绝仍保留 pending 与实际效果，不恢复、退款或续办。见证完成后的返回复核若发现租约过期、时钟回退或当前权限撤销，不返回凭据；已经确定完成的账本与 current 保留，不能据异常假设写入未发生。该规则不允许绕过未决见证。

## 本地证据与范围

测试覆盖真实本地 FileStore、完整 SQL／文件来源、工厂、持有者及资源权限、错误令牌、容量竞争、普通续期／释放／清理、引用参数篡改、重入、永久存储、两种写入阶段拒绝及异常脱敏。额外测试在见证最终检查中推进／回退时钟或撤销权限，验证不返回失效凭据。测试只保留失败状态，没有执行跨安全代际交接、未知结果续办或最终账号恢复启用；普通租约业务 epoch 与账号安全代际没有混用。

首次代码的时钟原始异常泄露及最终检查后返回过期凭据均有独立失败日志。修正前后快照分别记账，不能把早期通过当作最终源码的一轮通过。准确结果以 [证据目录](native-leases-evidence-2026-10-22/) 为准。上传隔离保护图、其他尚未分类入口、旧 PHP 7.2 超时、暂缓功能和外部验收仍开放，goal 不标记完成。

最终记录：早期快照九版 99/99 命令及两端 MySQL 16/16 套通过，消费者 19/20 通过；PHP 7.2 normal 消费者约 1.724 秒触发 `sql.timeout`，根因未确认。返回复核修正只改变 StateLeaseConnection；最终快照九版受影响路径及新增返回时序场景 45/45、两端 MySQL 8/8、归档／离线全新消费者 14/14、两端语法 16/16、PHPStan 全部通过。五个运行时文件与最终安装包摘要一致，消费者已清理，两轮 MySQL 控制器均正常退出并执行自身资源清理。PHP 7.2 MySQL 明确使用既有单调时钟／sodium 包装，不能声称默认时钟失败已解决；可选 turbo 扩展的 GLIBC 警告保留。两份快照及首次失败保持分开，详见 [result.json](native-leases-evidence-2026-10-22/result.json)、completion/source-difference.json 和各阶段驱动脚本，不合并成全项目验收。
