# 独立状态权威的受控代际交接候选

本阶段继续 R2.7 的完整备份恢复防御，承接[未决权威关闭](account-state-retirement.md)。实现位于本地隔离候选 `/tmp/sosecurity-state-successor-tk2v5zrv`，尚未接入 SDK；不能据此宣布账号恢复、新鲜度防御或完整 R1—R6 完成。

## 交接约束

旧权威必须先经过真实独立管理角色、近期强认证、重新认证和一次性授权，永久转为 `closed`。新的 `StateSuccessorReview` 绑定准确关闭记录的完整封存字节摘要、旧修订、原操作描述摘要、当前观测状态、独立审批配置和随机新代际，预览有效期最多 120 秒。预览本身不代表审批。

`StateRetirementControl` 增加固定 `state.successor.stage` 动作的独立授权流程，只接受具体不可变预览类，仍绑定实际 Grants 的认证期限与方法，不接受任意布尔审批结果。新一轮确认必须在重新认证后产生，与旧关闭授权不能互换；最终角色／会话／期限复核在写入前后执行。

交接使用原权威路径和同一 inode 的排他锁，不能创建新文件绕开旧未决记录。`successorReader()` 仅创建使用相同 PDO、快照、密钥和持久化依赖的读取器；它不读取、初始化或更换文件，也不授予恢复权限。

审批完成后，原文件写入显式格式 3 的 `quarantined` 记录，包含预期新代际、准确前驱摘要、原未知操作标识和完整操作描述、审批回执以及新的交接动作。原可信检查点摘要保持，当前观测状态不会自动成为可信基线。完整旧封存记录可在交接前由宿主归档，以其准确摘要关联；新回执保持 4096 字节上限。

格式 1／2 读取器拒绝格式 3；格式 3 读取器必须匹配配置中的预期代际。隔离状态允许读取回执，所有普通工作入口拒绝执行，不能使用 `initialize()` 覆盖已有权威。写入或后续复核失败返回 `account.completion_unknown`，不能恢复为旧 `current`、重放原操作或自动采纳当前数据库。

## 见证锁归属

`LocalStateWitness` 候选增加进程／原生 Fiber 的持锁归属检查。子进程退出继承的调用栈时只关闭自己的句柄副本，不执行会影响父进程的 `LOCK_UN`；读取、快照和写入均须处于原执行上下文。准确旧源码反例在父进程仍处于工作区间时实际取得另一把排他锁并写入测试数据库，修正版拒绝该写入。

## 本地验证

首轮 PHP 7.2／8.5 共 34 组定向检查全部通过；该轮之后补充了原操作描述的回执保留，因此不能替代补充后的验证。两版准确旧见证源码反例按危险写入标记失败，修正版各 5 项断言通过。首次新测试因缺失测试预算函数而未进入工作区间，已修正；它不作为运行时代码失败或安全反例。

最终 38 份候选源码、636 份相关输入在九版本矩阵及私有 MySQL 后保持不变。684 条矩阵中 675 条关联／语法执行通过，9 条 API 检查因把候选覆盖类用于只认主源码路径的反射脚本而失败，原日志保留；补充复核主 SDK 原 211 类九版通过，同时允许准确两种源码路径，对候选覆盖的原 211 类完整公开成员与上一版候选逐项对照，九版均保持。不能声称原 684 条矩阵全绿，也没有把新增候选类当成已冻结公开接口。

两版私有无 TCP MySQL 共 24 组、每版 289 项断言通过，原控制器退出 0，实例 `/tmp/sosecurity-mysql-pto9pm9b` 已清理。补充后的目标 PHP7.2／level5 静态通过；初次分析器 128MiB 上限中止单列。验收为候选目录的 `acceptance.json`，原矩阵／修正反射／MySQL 终态／锁反例分别保存在 `successor-final-report.json`、`api-corrected-report.json`、`mysql-exit.json` 和 `witness-owner-report.json`。四个没有原生 Fiber 的运行时只执行上下文脚本中的进程部分，不能声称执行 Fiber 路径。

测试只使用自有临时 SQLite 文件和 `/tmp/sosecurity-mysql-*` 内的无 TCP 实例，独立审批环境使用另一套实际本地认证数据库与目录。没有业务数据库、生产数据、外部邮件或真实服务调用。

## 尚待完成

本阶段仅建立受审批且仍隔离的代际交接。后续必须完成隔离中的账号凭据／会话／因子处理、通知与队列的准确处置、全宿主写入入口及代际传播，然后才可设计并验证明确的业务恢复提交。SDK 工厂、诊断、原生表单与 CSRF、消费者安装及完整整合门禁继续；不能添加一个任意回调或“信任当前数据库”开关代替这些要求。

[隔离代际中的账号处置候选](account-state-containment.md)已开始提供固定批次禁用操作；它保持隔离，不能代替最终账号／因子／队列恢复提交。
