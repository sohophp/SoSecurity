# 因子物理处置的未决效果收敛

更新：2026-10-19。隔离候选 `/tmp/sosecurity-state-factor-resolution-sized-p0y63z85` 接续[物理处置](account-state-factor-containment.md)，其中的[只读快照基础](state-snapshots.md)现已并入主SDK；本页恢复权威／审批／清理／安全代际流程仍为独立候选，不是完整规划或生产验收。

## 固定持久化清单

原物理处置在消费批准及修改文件前，验证清单与已审阅组合观测相同；在原见证文件封存实际来源指纹、文件来源、因子命名空间引用、最多四个唯一逻辑键／文件名、旧原始字节摘要（缺失独立表示）和准确预期永久空封存。清单没有旧密钥、旧恢复码、旧正文或可激活材料。执行时重新取得原始文件，要求与已持久化清单完全相同，才安装专用写入能力。

清单返回值不是能力；仅持有清单或自行构造计划不能写入。新计划复制嵌套数组以隔离PHP引用，再验证每个预期值的完整封存及 `payload=null`。同一目录下改变命名空间、来源或覆盖关系均拒绝。

## 新审批与续办

`StateFactorResolutionReview` 使用独立 `resolve_factors` 用途、签名域和 `state.factors.resolve` 授权动作。真实管理角色、近期密码／MFA、准备后重新认证及一次性批准全部复核；旧处置批准不能替代新批准。预览绑定准确未决根摘要、原清单、当前完整来源和本次尝试序号，过期或来源变化须重新审阅。

新批准消费后先封存本次未决尝试，再在同一进程／Fiber和真实期限内，只把清单内仍为原字节或已为预期空封存的文件写成该准确空封存；即使文件已是预期值，也重新确认持久化。共享原物理处置的永久条带锁、原始字节CAS、重命名前后确认及目录／句柄检查。其他字节拒绝，不能在新审批中偷偷采纳。

成功只把该批物理处置标成完成，原可信摘要、未知操作、原审批及清单保留，账号仍为隔离状态。新尝试失败继续pending，旧预览不可重放；再续办必须新预览、新批准和递增序号。本次回执链接前一完整根摘要，不无限嵌套历史对象。流程不重新解释原目录序号，即使目录历史后来不可用，仍只处理原清单的文件，不能据此启用业务。
