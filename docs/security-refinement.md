- 可调用 API、最小示例、场景文档、稳定错误码及资源预算。
- 正常、拒绝、过期、重放、并发、损坏状态和依赖故障；拒绝发生在相关业务副作用前。
- 新状态具有格式版本、严格结构校验与迁移／失效策略。事务回调可重试，不在回调中执行网络、通知或随机值生成。

- 身份、权限、签名和一次性授权失败拒绝操作；观察模式仅适用于明确允许观察的策略。
