# 完整 SQL 来源的分组结构读取

MySQL 在同一次完整捕获内按最多四张表分组读取列和主键元数据；每组仍在行读取前后分别核对完整结构，不缓存或跨请求复用。表名、引擎、列、主键、容量和摘要验证保持，SQLite 路径仅移除冗余条件。没有新增公开 API，清单仍为275个类型。

五张表的捕获 SQL 调用由40次减少为28次，空状态及不同表的数据摘要与修前基准一致。原生凭据身份捕获的预备语句执行次数由分别312／合并208降至168／112。这些是对应测试数据下的计数，不是整个请求性能保证。
