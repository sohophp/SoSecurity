# 默认签发耗时：外键查询拆分实验

当前默认 MySQL 凭据签发的 3000ms 预算失败仍未解决。本次只验证一个优化假设：把私有表外键依赖检查中的入站／出站 OR 分成 UNION ALL，保持原有条件和 LIMIT 1。

在自建、关闭网络的 MySQL 实例中，PHP 8.5 对无依赖、入站、关闭外键检查、跨库入站、出站、仅大小写不同的其他表六种情形进行比较。每种查询每种情形执行100次，并检查只读账号的可见结果，共1212项断言已执行并通过。使用单调时间测量探针，不修改产品时钟或系统配置。

结果：现行查询合计约0.648秒，拆分查询合计约0.836秒，六种情形均更慢。本次结果不支持采纳，因此未修改运行时源码、未调整预算，也未再次运行默认签发。该实验只排除当前查询拆分候选，不能证明默认签发性能通过。

另核对 SqlStateAccess：连接准入调用已注册的执行上下文检查，不能将其直接归为重复完整来源扫描。FactorWorkerAuthority 的事务探测和随后 enlist 确有两次事务状态检查，但后者负责独立的事务所有权边界，本次未删除；账本检查和实时身份检查也保持。
