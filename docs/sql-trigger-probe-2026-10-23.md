# 同次SQL结构观测中的触发器读取去重

当前SqlSchema在同一MySQL语句内两次读取同一表的触发器：权限可见性证明的单行派生结果已计算has_trigger，列分支又独立执行相同EXISTS。修前实际计数为2，新查询预算断言要求1并复现失败，见[修前日志](sql-trigger-probe-evidence-2026-10-23/before-query-budget.log)。

修复仅让列分支使用同一语句已物化的visibility.has_trigger；保留原字段与拒绝条件、身份格式、直接TRIGGER可见权限、partial_revokes检查、外键与额外唯一约束拒绝、列／索引预算、事务及回调后重验。没有跨语句或跨回调缓存权限／结构结果。SQLite路径、规范DDL、存储格式、公开API277及默认预算均保持。

## 对照与候选核对
